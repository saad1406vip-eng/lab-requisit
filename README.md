# 🧪 تطبيق إدارة طلبات المختبر الطبي

تطبيق احترافي لإدارة طلبات المستهلكات والمواد في المختبرات الطبية - نسخة ويب متقدمة مع حفظ البيانات محليًا وطباعة/تصدير الطلبيات.

## ✨ المميزات الرئيسية

✅ **قاعدة بيانات شاملة** - تحتوي على جميع البنود المتاحة للمختبر من الملف الأصلي
- اختبارات كيمياء (Chemistry)
- اختبارات بيور (Biochemistry)
- هرمونات وفحوصات إضافية
- مستهلكات وأدوات (Supplies)
- أمراض الدم والتخثر (Hematology)
- اختبارات ميكروبيولوجيا (Microbiology)
- وغيرها...

✅ **واجهة احترافية وسهلة الاستخدام**
- تصميم عربي 100% متوافق
- تنسيق ملون وجذاب
- استجابة كاملة على جميع الأجهزة

✅ **إدارة الطلبيات الذكية**
- إضافة العناصر للطلبية بنقرة واحدة
- تعديل الكميات مباشرة
- حساب تلقائي للإجمالي
- حذف العناصر غير المطلوبة

✅ **البحث والتصفية المتقدمة**
- بحث سريع باسم المادة أو الكود
- تصفية حسب الفئة
- عرض فوري للنتائج

✅ **الطباعة والتصدير**
- طباعة الطلبية بصيغة احترافية مع العنوان والتاريخ
- تصدير CSV للتقارير
- إثبات رسمي مع الوقت والتاريخ
- توقيع آلي بالرقم المرجعي

✅ **حفظ البيانات المحلي**
- حفظ تلقائي في localStorage
- استعادة الطلبية عند إغلاق وفتح التطبيق
- لا حاجة لخادم أو قاعدة بيانات

✅ **متوافق 100% مع جميع المتصفحات**
- Chrome / Firefox / Safari / Edge
- الهواتف الذكية والأجهزة اللوحية

## 🚀 البدء السريع

### الطريقة 1: استخدام مباشر (الأسهل)
1. انسخ ملف `index.html`
2. افتحه في المتصفح
3. ابدأ الاستخدام فورًا

### الطريقة 2: النشر على GitHub Pages

#### الخطوة 1: إنشاء حساب GitHub
- اذهب إلى [github.com](https://github.com)
- أنشئ حسابًا جديدًا أو تسجيل الدخول

#### الخطوة 2: إنشاء مستودع جديد
1. انقر على `+` بجانب اسمك
2. اختر `New repository`
3. اسم المستودع: `lab-requisition-app`
4. وصف: `تطبيق إدارة طلبات المختبر الطبي`
5. اختر `Public`
6. انقر `Create repository`

#### الخطوة 3: رفع الملفات
**عبر الويب:**
1. انقر على `Add file` → `Upload files`
2. اسحب أو اختر الملفات:
   - `index.html` (الملف الرئيسي)
   - `lab-requisition-app.jsx` (الكود الكامل)
   - `README.md` (هذا الملف)
3. اكتب رسالة commit: "Initial commit - Lab Requisition App"
4. انقر `Commit changes`

**عبر سطر الأوامر (Git):**
```bash
# استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/lab-requisition-app.git
cd lab-requisition-app

# إضافة الملفات
git add .

# حفظ التغييرات
git commit -m "Initial commit - Lab Requisition App"

# رفع للمستودع
git push origin main
```

#### الخطوة 4: تفعيل GitHub Pages
1. اذهب إلى إعدادات المستودع (Settings)
2. من الشريط الجانبي، اختر `Pages`
3. اختر `Deploy from a branch`
4. اختر `main` branch و `/ (root)` folder
5. انقر `Save`

**سيتم نشر التطبيق على:**
`https://YOUR_USERNAME.github.io/lab-requisition-app/`

## 📖 كيفية الاستخدام

### إضافة طلبية جديدة
1. اختر الفئة من قائمة التصفية (اختياري)
2. ابحث عن المادة بالاسم أو الكود
3. انقر على زر "أضف للطلبية"
4. كرر العملية لإضافة مواد أخرى

### تعديل الطلبية
1. انقر على زر "الطلبية" في الأعلى
2. غير الكميات مباشرة من الجدول
3. استخدم الإجمالي المحسوب تلقائيًا
4. احذف أي عنصر غير مطلوب

### طباعة الطلبية
1. افتح الطلبية
2. انقر على "اطبع الطلبية" 🖨️
3. ستظهر نسخة جاهزة للطباعة
4. استخدم Ctrl+P أو ⌘+P للطباعة

### تصدير إلى Excel/CSV
1. افتح الطلبية
2. انقر على "تصدير CSV" 📥
3. سيتم تنزيل ملف يمكن فتحه في Excel
4. استخدمه في التقارير

## ❓ الأسئلة الشائعة

**س: هل يمكن استخدام التطبيق بدون إنترنت؟**
ج: نعم! بعد تحميل الصفحة الأولى، يعمل بكامل الوظائف بدون إنترنت.

**س: هل تحفظ البيانات بشكل دائم؟**
